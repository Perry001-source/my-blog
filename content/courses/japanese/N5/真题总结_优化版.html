0. 考前使用方法

复习阶段 怎么用 目标
考前 7 天 每天按模块背：助词 1 天、动词句型 1 天、形容词/数量词 1 天、阅读/听力 1 天，剩余时间刷错题。 把规则和真题句子绑定。

1. 助词固定搭配速查

1.1 高频助词总表

助词 核心功能 固定搭配 / 例句 易错提醒
に 时间点、存在地点、移动目标、对象 四時に起きます。
机の上に本があります。
学校に行きます。
友達に会います。		 强调“点”和“到达结果”。具体时间用 に，但「今日、明日、毎日」通常不用。
で 动作场所、方式手段、范围 レストランで食べます。
バスで行きます。
カタカナでお願いします。
一年で夏が一番好きです。		 强调“动作发生的过程/方法”。不要和存在地点 に 混。
が 主语、能力/喜好/状态对象、自然现象 猫が好きです。
日本語がわかります。
花が咲きます。
いい香りがします。		 中文像“宾语”的地方，日语常用 が：好き、わかる、ほしい。
を 他动词动作对象、经过/离开点 りんごを食べます。
テレビを見ます。
公園を散歩します。		 “主动对某物做动作”多用 を。喜欢/懂/想要不用 を。
と 并列、伴随、引用 本と鉛筆。
祖母と花を摘みました。
「さくら」と言います。		 A と B と、どちらが...：二选一时两个选项后常对称加 と。
の 名词连接、所属、名词化、代词化 私の本。
英語の先生。
食べるのが楽しみです。
大きいのをください。		 中文可省略“的”，日语两个名词连接时通常不能省略 の。
も 也、数量强调、全面否定 田中さんも行きます。
三時間も待ちました。
何もありません。		 も 会替换 は/が/を：私はも ×，私も ○；りんごをも ×，りんごも ○。
は 主题、对比、强调否定 私は学生です。
あした、テストはありません。		 否定时常用 は 强调“这个没有/这件事没有”。

1.2 で vs に：必考区分

对比 で に
地点 动作发生地：学校で勉強します。 存在地点/到达点：学校にいます。学校に行きます。
方式 交通/工具/语言：バスで、ペンで、カタカナで。 通常不用来表示工具手段。
判断口诀 有动作过程，看 で。 有坐标、目标、时间点，看 に。

1.3 を vs が：中文思维最容易错

类型 用法 例句
他动词动作对象 を：我对某物施加动作。 りんごを食べます。映画を見ます。
状态/能力/情感对象 が：某物本身成为状态焦点。 猫が好きです。日本語がわかります。休みがほしいです。

2. 动词形态与核心句型

句型 接续 意思 / 例句 考试提醒
Vて形 + います 電話して + います 正在做某事。
山下さんは今、電話しています。		 后面已经有「中です」时，不能再填「電話している」。
动作性名词 + 中です 電話 + 中です 处于某动作中。
山下さんは今、電話中です。		 中です 前面只能接名词：電話中です ○，電話している中です ×。
Vた形 + り、Vた形 + りします 聞いた + り、読んだ + りします 列举动作：做做 A、做做 B。
音楽を聞いたり、本を読んだりしています。		 前面有「たり」，后面通常也要找「たり」。句尾常有 します/しています。
Vて形 + から 掃除して + から 做完 A 之后再做 B。
玄関を掃除してから、台所を掃除します。		 强调先后顺序，听力里要立刻给动作排序。
Vた形 + あとで 終わった + あとで A 之后。
試験が終わったあとで、旅行に行きます。		 和「てから」意思接近，但接续不同：た形 + あとで。
Vます去ます + ながら 見ます → 見ながら 一边 A 一边 B。
テレビを見ながら、ご飯を食べます。		 不是て形。要从ます形去掉ます。
Vない形 + でください 忘れない + でください 请不要做某事。
帽子を忘れないでください。		 听力请求/提醒题常考。

2.1 动作连接：休んで vs 休みで

表达 判断 说明
少し休んで、何か飲みませんか。 正确 「休んで」是动词て形，表示“休息一下，然后喝点什么”。
少し休みで、何か飲みませんか。 错误 「休み」是名词，名词 + で不能连接“做完 A 再做 B”的动作流。

3. 形容词变形

类型 规则 例子 提醒
一类形容词
い形容词		 过去肯定：去 い + かったです 安い → 安かったです。
おいしい → おいしかったです。		 词尾是 い，多数按这个规则。
一类形容词
い形容词		 过去否定：去 い + くなかったです 安い → 安くない → 安くなかったです。
大きい → 大きくない → 大きくなかったです。		 先变否定「くない」，再把ない变过去。
二类形容词
な形容词		 过去肯定：词干 + でした しずか → しずかでした。 词干后不加 かった。
二类形容词
な形容词		 过去否定：词干 + じゃありませんでした しずか → しずかじゃありませんでした。 N5 常见长选项，看到要能秒认。

4. 数量词与比较句

4.1 通用量词「つ」

12345678910
ひとつふたつみっつよっついつつむっつななつやっつここのつとお
高频陷阱：1-9 后面都有「つ」，10 是「とお」，没有「つ」。

4.2 数量词位置

结构 例句 说明
物品 + が/を + 数量词 + 动词 りんごが三つあります。
えんぴつを四本買いました。		 最常用，数量词放动词前。
数量词 + の + 物品 + が/を + 动词 三つのりんごがあります。
二匹の猫がいます。		 数量词放名词前时，中间必须加 の。

4.3 动物量词

量词 对象 例子
匹（ひき） 猫、狗、鱼、青蛙、昆虫等小动物 二匹の猫
頭（とう） 大象、马、牛等大型动物 一頭の馬
羽（わ） 鸟类，也包括兔子 三羽の鳥

4.4 比较句「のほうが」

句型 例句 考点
A と B と、どちらが + 形容词 + ですか。 コーヒーと紅茶と、どちらが好きですか。 二选一用 どちら。选项后常对称加 と。
A のほうが + 形容词 + です。 先月のほうがおいしかったです。 被偏爱的那一方后面加 のほうが。

5. 疑问词、指示词与交际表达

考点 用法 例句 / 判断
なにで 询问方式、交通工具、手段。 A：なにで学校へ行きますか。
B：バスです。
どちら vs どれ 二选一用 どちら；三选一及以上用 どれ。 コーヒーと紅茶 → どちら。
あめ、クッキー、チョコレート → どれ。
疑问词 + か 表示不确定的“某个/随便一点”。 何か飲みませんか。= 要不要喝点什么？
〜ませんか 委婉邀请，询问对方意愿。 コーヒーを飲みませんか。
〜ましょう 直接提议，一起做某事。 いっしょに食べましょう。
もう vs まだ もう：已经；まだ：还没。 もう食べましたか。
はい、もう食べました。
いいえ、まだです / まだ食べていません。
名词 + で + お願いします 用某种方式/工具拜托对方。 カタカナでお願いします。

6. 四大语法题型：临考解题框架

题型阵营 核心判断 高频搭配 拿分动作
助词固定搭配 看空格前后词性。 名词 + の + 名词；数量词 + の + 名词；A や B など；大主语 は + 小主语 が + 形容词。 先判断词性，再选助词。
疑问与指示 看答句、选项数量、距离关系。 なにで；どちら/どれ；何か；こそあど。 不要只看半句，必须看前后对话。
动词形态 盯空格前后的词尾。 たり；た形 + あとで；て形 + から；名词 + 中。 先看接续，再看意思。
副词与交际 看语气和对话反应。 ときどき + 肯定；あまり + 否定；もう/まだ；お願いします。 用下一句倒推上一句。

7. 星号排序题四步法

步骤 做法 例子 / 口诀
1. 看句尾 先找谓语，判断前面必须接什么。 います 前面常接存在主体；食べました 前面找地点/对象。
2. 找小模块 把固定搭配先绑起来。 銀行の近くの；もらった帽子；小さくて色が明るい。
3. 堆修饰语 日语修饰语放在被修饰词前面。 去年誕生日に兄にもらった帽子。
4. 核对星号 排完整句后再看星号位置，不要手滑。 口诀：先看句尾定最后，再找助词绑小块，长长修饰堆前面，最后顺藤找星号。

8. 阅读理解：时间、地点、方位线索

8.1 时间词

类别 重点词 提示
日期阶段 今日、昨日、明日、先週、来週、去年、夜 判断事情发生在哪一天。
频率习惯 毎日、いつも、ときどき、あまり あまり 后面要接否定。
时间界限 〜から、〜まで、〜の前に、〜の後で、もう、まだ 判断先后顺序和完成状态。

类别 重点词 提示
核心地点 家、店、スーパー、レストラン、学校、教室、駅、公園、山、海 圈出地点后面的 に/で/へ。
相对方位 近く、前、中、上、下、外、そば、向こう、真ん中 图表题和阅读定位题高频。

9.1 听力高频词表

类别 词汇 听力功能

9.2 听力核心语法

语法 例句 听到后要做什么
〜てから 玄関を掃除してから、台所を掃除します。 给动作排序：先玄关，后厨房。
〜にもらう / 〜がくれる 兄と姉にもらいました。父がくれました。 判断“谁给我”。もらう 是我收到，くれる 是别人给我。
〜のほうが 2番のほうが早いですよ。 后面常是最终选择。
〜ないでください 帽子を忘れないでください。 听成“不要忘记”，不是“忘记”。
もう / あまり もう掃除をしました。あまり読みませんでした。 もう + 完成；あまり + 否定。

9.3 社交口语：问题 3/4 常考

表达 意思 场景
お休みなさい。 晚安。 睡前。
いらっしゃいませ。 欢迎光临。 店员对客人。
ここ、いいですか。 这里可以吗？ 想坐在旁边空位。
これ、いかがですか。 这个怎么样？要不要来点？ 推荐、送东西、请别人吃。

〜てもいいですか。 可以做某事吗？ 征求许可。

9.4 听力题型拆解：先判断它在考什么

题型 常见问法 听的时候抓什么 避坑点
任务选择题 何をしますか。何を買いますか。 动作动词、对象名词、最后决定。 前面提到的不一定是答案，注意 じゃ、でも、やっぱり。
人物判断题 だれですか。だれが行きますか。 人物名 + 助词：が、は、に、から。 もらう/くれる 会改变视角。
时间判断题 いつですか。何時ですか。 今日、明日、来週、午前/午後、〜分前。 8時5分前 = 7:55，不是 8:05。
地点路线题 どこですか。どこへ行きますか。 駅、店、学校、前、右、左、そば、向こう。 に/へ 是目标，で 是动作地点。
图表匹配题 どれですか。 颜色、大小、形状、位置、数量。 先排除明显不符，再等最终修正。
即时应答题 何と言いますか。 场景身份：店员/客人、老师/学生、家人/朋友。 不要直译中文，要选日语场景里自然的回应。

9.5 听前 5 秒：先看选项，做标记

选项长什么样 说明 听前标记
都是时间 题目大概率问“什么时候”。 圈上午/下午、星期、数字、前/后。
都是地点 题目大概率问“在哪里/去哪里”。 圈方位词：前、右、左、中、そば、向こう。
都是物品 题目大概率问“买/拿/找哪个”。 圈颜色、大小、数量、厚薄、新旧。
都是人物 题目大概率问“谁做/谁给/给谁”。 圈人名，听助词：が、に、から。
都是动作 题目大概率问“接下来做什么”。 圈动词，重点等 じゃ、では、お願いします 后面的动作。
听力原则：选项先决定“我要听什么”。不要一上来试图听懂每个词，先抓题目需要的那一类信息。

9.6 数字、时间、价格：听力高危区

类别 必听表达 提醒

数量 一つ、二つ、三つ；一本、二本、三本；一枚、二枚 听清量词，物品类别可能直接决定答案。

9.10 听力训练方法：三遍法

遍数 任务 不要做什么
第一遍 只抓答案信息：人、时间、地点、物品、动作。 不要暂停，不要纠结没听懂的小词。
第二遍 对照原文，圈出没听出来的词和助词。 不要只看中文翻译。
第三遍 跟读原文，尤其是数字、て形、ないでください、方位词。 不要默读，听力要让耳朵熟悉声音。

9.11 问题 1：看图任务题的“最后落点”

真题场景 关键听法 答案锁定句
集合地点 先听女生提出的错误假设，再等老师用 いいえ 修正。 いいえ、駅に来てください。= 不是学校，是车站。
放椅子 位置题要把“基准物 + 方位”连起来听。 机の左側、窓のそば = 桌子左边、窗户旁。
拿书 颜色、厚薄连续排除，听 いいえ 后面的真实属性。 白い本、薄い本 = 白色薄书。
问路 先顺路线，再听确认句里的左右。 この道をまっすぐ、その向こう、この道の右側。
买花 数量题注意“追加”。リボン 等包装信息可能只是干扰。 二本 + もう一本 = 三本；リボンは要りません。
打扫准备 分清“别人带什么”和“自己要带什么”。 お茶はわたしが持っていきますから、カップを持ってきてください。
等巴士 先排除不去的车，再等比较句决定最终选择。 2番のほうが早いですよ。じゃ、少し待ちます。
问题 1 做题顺序：看图先圈差异：地点、左右、颜色、数量、交通编号。录音中凡是出现 いいえ、もう、じゃ、のほうが，立刻回到选项重新排除。

9.12 问题 2：带着题目关键词听长对话

题目问什么 常见陷阱 考场反应
谁送的 先提到的物品不一定是题目问的物品。 题目问 帽子，就只等 この帽子。父がくれました = 父亲给的。
星期几 多个星期连发，其他老师和没有课都是排除项。 わたしは月曜日に教えます = 山田老师星期一上课。
打扫哪里 お願い 的任务可能被 もう 覆盖。 トイレはもう掃除をしたよ。じゃ、庭の掃除 = 院子。
几楼 餐厅、浴室、房间会配不同楼层。 レストラン=1/2階；お風呂=10階；部屋=8階。
昨天做什么 毎週 是习惯，不等于昨日。 昨日は家で本を読みました。行きませんでした 要排除。
几点见面 初始时间会因闭店、迟到、改约而作废。 8時5分前 = 7:55。听到 でも 后重算。
问题 2 高危误选：题目问“昨天”，不要选“每周”；题目问“帽子”，不要选“毛衣”；题目问“学生房间”，不要选“餐厅/浴室”。

9.13 问题 3：看图社交句，抓「想做什么」

旁白关键词 应该选的自然表达 不要选什么
今から寝ます お休みなさい。 こんばんは 是见面寒暄；さようなら 是分别。
時間が知りたいです 今何時ですか。 いくらですか 问价格；どのぐらい 问程度/时长。
座りたいです ここ、いいですか。 不要用过去否定式 座りませんでしたか。
お菓子をあげたいです これ、いかがですか。 どうしてですか 是问原因。
カメラを見たいです このカメラを見せてください。 見せたいです 是“我想给别人看”，视角错。
问题 3 秒解法：旁白里的「〜たいです」告诉你“我想做什么”。答案通常不是直译，而是对对方说的请求、寒暄或许可表达。

9.14 问题 4：即时应答靠疑问词反射

听到 立刻找 真题式正确回应
何で 交通工具、手段 自転車で来ます。電車で行きます。
誰の 所属者 わたしのです。田中さんのです。
いくつ 数量 三つです。五つ並べます。
だれ 人物身份 わたしの妹です。山田先生です。
どこかへ行きますか 具体去处或活动 山に登ります。友達の家へ行きます。
ましたか / 子供のとき 过去式回答 あまり読みませんでした。よく行きました。
问题 4 检查尾巴：题干是过去时，选项也要优先找 ました / ませんでした。题干问交通、数量、所属、人物时，不要被选项里重复的词带走，要回答疑问词本身。

9.15 逐题错因压缩清单

错因 表现 修正动作
听到第一个信息就选 8:20、3号巴士、厕所、黑色书这类前置信息容易诱导。 等 いいえ / でも / じゃ / もう / のほうが 后面的落点。
没有绑定题目关键词 问帽子却记毛衣，问房间却记餐厅。 听前在选项旁写：物品、人、时间、地点、动作。
数字没做换算 〜分前、もう一本、1時間ぐらい 后修改时间。 听到数字立即写算式：2+1=3；8:00-5分=7:55。
助词视角混乱 先生に会う、電車に乗る、父がくれる、兄にもらう。 に=对象/乘坐/目标；が=动作主语；を=动作对象。
把中文直译成日语 想看商品时误选 見たいです 或 見せたいです。 对店员请求用 見せてください；想坐下用 ここ、いいですか。

10. 历史真题扩展：高频补充模块

这一部分按历年 N5 真题常见出题方式补充：题目通常不直接问“语法名”，而是通过空格前后的词性、答句、场景和选项差异来考。

10.1 存在句：あります / います

句型 意思 真题式例句
场所 + に + 物 + が + あります 某地有某物。 机の上に本があります。
场所 + に + 人/动物 + が + います 某地有人或动物。 庭に犬がいます。
物/人 + は + 场所 + に + あります/います 某物/某人在某地。 トイレはあちらにあります。田中さんは教室にいます。
易错：非生命物用 あります，人和动物用 います。考试里看到句尾是 います，前面通常要找人或动物。

10.2 授受动词：もらう / くれる / あげる

动词 视角 助词搭配 例句
もらう 我/我方收到 A に B をもらいます 兄に帽子をもらいました。
くれる 别人给我/我方 A が B をくれます 父が時計をくれました。
あげる 我/别人给别人 A に B をあげます 友達に花をあげました。
听力判断：もらいました 要问“从谁那里收到”；くれました 要问“谁给了我”。

10.3 愿望、邀请、许可、禁止

句型 意思 例句 考点
名词 + が + ほしいです 想要某物 新しいかばんがほしいです。 ほしい 前面用 が。
Vます去ます + たいです 想做某事 日本へ行きたいです。 行きます → 行きたい。
Vて形 + ください 请做某事 名前を書いてください。 请求/指令题常考。
Vない形 + でください 请不要做某事 ここで写真を撮らないでください。 否定请求，不要漏掉 ない。
Vて形 + もいいですか 可以做某事吗 ここに座ってもいいですか。 征求许可。

10.4 频率副词：肯定/否定搭配

副词 意思 后面常接
いつも 总是 肯定：いつも行きます。
よく 经常 肯定：よく本を読みます。
ときどき 有时 肯定：ときどき映画を見ます。
あまり 不太 否定：あまり読みません。
ぜんぜん 完全不 否定：ぜんぜんわかりません。

10.5 动词变形入口表

目标形 常见用途 例子 快速记忆
ます形 礼貌表达、接 たい、ながら 読みます → 読みたい / 読みながら 去ます后接。
て形 连接、请求、许可、正在 読んで、読んでください、読んでもいい、読んでいます N5 使用频率最高。
た形 过去简体、たり、あとで 読んだ、読んだり、読んだあとで 形态常和て形相近。
ない形 否定、禁止请求 読まない、読まないでください 看到 でください 前有ない，就是“请不要”。

10.6 历史真题常见“陷阱信号词”

信号词 常见作用 做题反应
でも 转折 前面可能是铺垫，后面更重要。
じゃ / では 得出决定 后面常是最终行动或答案。
いいえ 否定前句 不要被前一个选项带走。
やっぱり 改变后确认 后面通常是最终选择。
〜のほうが 比较后偏向 标记被选择的一方。

12. 最后 30 分钟背诵清单

必须秒反应 内容
助词 に=点/目标/存在；で=动作场所/手段；が=喜好能力状态；を=他动词对象；の=名词连接；も=替换は/が/を。
动词接续 ている=正在；名词+中=正在；たり=列举；てから=之后；た形+あとで=之后；ます去ます+ながら=一边一边。
问答逻辑 なにで问交通工具；どちら二选一；どれ三选一以上；何か=某些东西；もう问完成，まだ答未完成。
阅读听力 圈时间、地点、方位、助词；听到 いいえ、でも、じゃ、のほうが，后面常改变答案或给最终答案。
